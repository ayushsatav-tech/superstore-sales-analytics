# Superstore Sales Analytics Dashboard
## 🚀 Live Demo

[Click here to view the live dashboard](https://ayushsatav-tech-ncinajukvufdw8m8ay9wqc.streamlit.app/)

## Project Overview
A Python-based Business Analytics project that analyses Superstore sales data and presents important business insights through an interactive Streamlit dashboard.

## Objectives
- Analyse total sales and profit.
- Identify regional sales performance.
- Understand the relationship between sales and profit.
- Study monthly sales trends.
- Provide interactive data filtering.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Project Structure
```text
superstore-sales-analytics/
├── app.py
├── analysis.py
├── requirements.txt
├── README.md
└── data/
    └── superstore.csv
```

## Features
- Sales and profit summary
- Regional performance charts
- Sales vs Profit visualization
- Monthly sales trend
- Interactive region filters
- Filtered CSV download

## Installation

Clone the repository:

```bash
git clone https://github.com/ayushsatav-tech/superstore-sales-analytics.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run app.py
```

## Dataset
Place the Superstore CSV file at `data/superstore.csv`.
